# Sofa Simulator 3D: Assi Edition

Browserspiel für das Handy (Hochformat). Testversion.

**Assi Simulator (Version 2 mit echten Bildern):** https://n3r0x89.github.io/sofa-simulator/v2/ (Ordner `v2/`). Die alte 3D-Version bleibt unter dem bisherigen Link.

**Nur für Erwachsene (18+).** Das Spiel zeigt Rauchen und Alkohol, hat derbe Beleidigungen und schwarzen Humor. Alle Sendungen und Personen sind erfunden.

## Spielen
Link auf dem Handy im Browser öffnen (Chrome oder Safari). Online nötig, beim ersten Laden dauert es einen Moment.
Für Vollbild: im Browser „Zum Home-Bildschirm“ wählen, dann startet es wie eine App.

## Bedienung
- Fernbedienung auf dem Tisch antippen, dann nach links oder rechts wischen: Sender wechseln.
- Flasche gedrückt halten: trinken. Neue Flasche: Bierkiste antippen.
- Im Suff die Flasche schnell nach oben wischen: gegen die Wand schmeißen.
- Handy antippen: Jobs. Konsole antippen: Spiele. 🛏️ oben: pennen. 🛒 Shop, 📖 Tagebuch.
- Meldungen schließt du mit einem Tipp irgendwo auf den Bildschirm.
